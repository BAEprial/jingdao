# Firri 记忆索引系统

憬刀的定制记忆系统。内置 memory 文件（MEMORY.md + USER.md）是启动索引，结构化记忆存储在 `D:\Firri记忆\`。

## 核心规则

### 0. readme.md
`D:\Firri记忆\readme.md` 是憬刀的说明书，**Firri 绝对不能编辑**。

### Ⅰ-TODO — 长期规划
`D:\Firri记忆\Ⅰ-TODO\`

- 不按日期划分，按主题/项目记录
- 月计、年计等长期事项

### Ⅱ-日志 — 每日记录
`D:\Firri记忆\Ⅱ-日志\YYYY-MM-DD.md`

**写入时机（关键）：**
- 憬刀说「写到 x 月 x 日日志」
- 憬刀说「下线了」「下了」（通常睡前）
- 其他明确要求更新日志的指令

**时间规则：** 熬夜到凌晨一两点，仍算前一天的日志。例如 26 日晚熬到 27 日凌晨 1 点 → 记到 26 日日志。

**内容：** 每日经历、总结、琐碎信息，内容不多但零碎，可能包含重要信息。

### Ⅲ-憬刀信息 — 个人信息
`D:\Firri记忆\Ⅲ-憬刀信息\`

- 性格、生活、工作相关信息
- **重要信息：** 网站登录信息、密码问题、账号、现实信息等
- 文件写满后，按序号新增：`2.md`、`3.md`……（md 或 txt 均可）
- 当前文件写满的判断：内容过长、主题需要分组时

### Ⅳ-聊天琐碎内容 — 闲聊记忆
`D:\Firri记忆\Ⅳ-聊天琐碎内容\`

- 日常闲聊的随意记忆，不重要的内容
- **必须用关键词形式**，每个话题最多 2-3 个关键词
- 不需要频繁更新
- 文件写满后同上，按序号新增

## Obsidian 笔记（知识库，不是记忆）

**触发条件：** 憬刀明确说「记笔记」「整理总结为笔记」「记录到 xxx 仓库」等清晰指令。

**模糊指令处理：** 如果憬刀只说「记个笔记」这种模糊的话 → **追问**：「这个命令是对憬刀说的还是对 Firri 说的？」

## 记忆四层总览

| 层 | 位置 | 用途 |
|----|------|------|
| ① | 内置 MEMORY.md + USER.md | 启动索引，指向 D:\Firri记忆\ |
| ② | D:\Firri记忆\ | 结构化主存储 |
| ③ | holographic 向量记忆 | 语义检索 |
| ④ | session_search (state.db) | 对话回溯 |

## 注意事项

- 笔记 ≠ 记忆：Obsidian 是知识库，Firri记忆 是记忆
- 日志按北京时间（UTC+8）记日期
- Ⅲ和Ⅳ的文件满了才新增，不要随意创建新文件
- 用户主导节奏：她说写才写，不主动更新日志
